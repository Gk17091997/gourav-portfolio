- `googlebot` specific directives: For Google crawling
- `hreflang` tags: For language/region targeting
- `distribution` meta: Global content indicator
- `revisit-after`: Crawler refresh guidance

## 13. **Files Reference**

### **robots.txt**
Controls what search engines crawl. Allows all search engines and specifies sitemap location.

### **sitemap.xml**
Lists all important pages with:
- Last modified date
- Change frequency
- Priority level

### **netlify.toml**
Configures:
- HTTP headers (SEO, security, caching)
- Content-type headers
- Asset caching rules

### **_redirects**
Ensures proper URL routing for the single-page app.
